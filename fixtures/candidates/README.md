# Каталоги кандидатов

В этих каталогах разрешено хранить только открытые или специально созданные обезличенные fixtures. Каждый добавленный файл обязан быть указан в README своего кандидата с SHA-256, версией формата, сценарием и источником.

Пустой каталог означает отсутствие разрешённых входных данных, а не поддержку платформы. Реальные конфигурации, результаты работы и данные заказчиков запрещены.
