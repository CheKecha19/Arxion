# Fixtures Firewall Assurance

`policy_quality.cfg` специально создан для тестирования в проекте, не получен от заказчика и не содержит клиентских данных. Используются документальные адреса 192.0.2.0/24, 198.51.100.0/24 и 203.0.113.0/24. Формат: ограниченный текстовый экспорт Cisco ASA 9.16.

Сценарии: deny перед более узким permit, дубликат, соседние кандидаты на объединение, разрешение any-any для UDP 53, отсутствие логирования и описания, remark и inactive. Контроль SHA-256 находится в `manifest.json` и проверяется интеграционным тестом.
