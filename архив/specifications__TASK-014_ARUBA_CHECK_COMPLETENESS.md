# TASK-014 — Полнота анализа ACL HP/Aruba

Дата: 11.10.2026.
Статус: реализация и автоматические проверки завершены; native проверка не выполнена.

## Цель и контекст

Отделить ограничения платформы от неполноты ACL, выполнить пригодные попарные
проверки и объяснить пропуски. Основание: аудит текущего Aruba adapter и согласование
в чате. Связанные документы: SUPPORTED_PLATFORMS, ARCHITECTURE, DEVELOPMENT_RULES,
TASK-011 и TASK-013. Сетевые ограничения TASK-008 остаются в силе.

## Область задачи

- Scope warning сохраняется в отчёте, но не отключает известную ACL.
- Source map локализует ограничения по ACL/привязкам. Ошибка без надёжной области
  блокирует попарный анализ целиком; неполная ACL не сравнивается как полная.
- Проверки используют только известные условия, порядок и область. Management и
  непривязанные ACL не подменяются transit-семантикой.
- Метаданные комментариев/logging не становятся неизвестными условиями пакета.
- AOS-S remark и CX comment сохраняются в description с отдельной строкой evidence.
- Permit log: распознанные release AOS-S 16.10+ и CX 10.13+; неизвестные версии
  дают logging unknown. Count не означает logging.
- Qt и HTML показывают выполнение и причины; ноль находок не означает пропуск.

## Вне области

Comware, IPv6, новые сетевые проверки, runtime logging, implicit actions,
ArubaOS controllers, итоговая достижимость и автоматическая подстановка адресов.

## Критерии приёмки и проверка

Поддержанные ACL дают findings дубликатов, затенения и объединения. Регрессии
проверяют неизвестную ACE внутри той же ACL, другую неполную ACL, отсутствующую
привязку, metadata-only ограничения, комментарии, release и source evidence.
HTML статусы и ограничения экранируются. Старые результаты читаются без миграции.

Полный pytest: 1265 passed; Ruff/format и mypy (68 файлов) прошли. Native оконный
прогон был отклонён и не выполнялся; факт проверки нового окна здесь не заявляется.
Portable EXE и ZIP собраны успешно. Текущий EXE пользователя запущен и блокирует
перезапись DLL, поэтому обновление находится в `../dist/ArubaUpdate/FirewallCompliance/`,
архив — `../dist/FirewallCompliance-ArubaUpdate-windows-x64.zip`. Запущенное приложение
не закрывалось. В build script добавлена защита от перезаписи работающей поставки и
ключ -ArubaUpdate. Сам новый EXE не запускался; packaged runtime QA не заявляется.

## Безопасность, совместимость и версии

Тестовые данные synthetic. Реальные исходники не изменяются и не сохраняются
полностью. SHA-256, evidence budgets и раздельное хранение решений сохранены.
HP/Aruba parser: 0.2.0; Aruba checks/catalog: 1.1.0. Другие checks сохраняют 1.0.0.
JSON schema и SQLite schema остаются прежними. CHECK_NOT_EXECUTED — новый код
ограничения в существующем partial, не новый enum. Старые отчёты неизменны.

## Запись о завершении

Обновлены SUPPORTED_PLATFORMS, USER_GUIDE, CURRENT_STATE и миграционные заметки.
Для новых выводов пользователь повторно запускает анализ; masked/unknown входы
по-прежнему ограничивают результат. Новый срез не заявляет полную поддержку Aruba.
