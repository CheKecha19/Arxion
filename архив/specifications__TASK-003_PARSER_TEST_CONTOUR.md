# TASK-003: Нейтральный тестовый контур парсеров

Приоритет: P0
Статус: Готово
Дата завершения: 2026-10-09

## Ценность

Новый парсер можно реализовывать и изменять без привязки к файловой системе или конкретному производителю, а его поведение защищено единым контрактом и фиксированными эталонами сериализации.

## Реализовано

- Три разрешённых legacy-fixtures перенесены в `tests/fixtures/legacy/` с контролем SHA-256. Исходный проект не изменялся.
- Исторический baseline сохранён в `tests/fixtures/legacy/BASELINE.md`: `2/9/8` относится только к legacy-парсерам. Для будущего UserGate-адаптера ожидаются `3` и `10` правил, потому что блокирующие действия также входят в модель.
- Созданы нейтральные контракты `SourceDocument`, `DetectionResult`, `ParseRequest`, `ParseFailure`, `ParseOutcome`, `ConfigurationParser` и `ParserRegistry`.
- Чтение файла вынесено в инфраструктурный `FileSourceReader`; адаптер парсера получает только документ в памяти.
- Реализованы contract tests: неизменяемость detection, успешный `ParseResult`, обязательный source mapping, сохранение статусов unknown/unsupported, сохранение действия `drop`, отсутствие и неоднозначность подходящего парсера.
- Добавлены golden-тесты. Эталон хранится в JSON, UUID, время и хеш фиксированы. Изменение эталона требует явной команды `uv run python scripts/update_golden.py --confirm ...`.
- Добавлен интеграционный сценарий от `SourceDocument` до `ParseOutcome` через registry.

## Границы

Ни один производитель или формат конфигурации ещё не объявлен поддерживаемым. До Фазы 5 требуется отдельное ADR о первом production-quality парсере.

## Проверка

```powershell
uv run ruff format --check src tests scripts
uv run ruff check src tests scripts
uv run mypy src
uv run pytest
```

Фактический результат на 2026-10-09: Ruff и mypy прошли без замечаний, pytest выполнил 30 тестов успешно. В изолированном окружении использован новый временный `uv` cache; прежний недоступный cache не изменялся.
