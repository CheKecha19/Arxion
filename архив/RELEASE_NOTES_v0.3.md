> Исторические заметки подготовки 0.3.0. Ограничения GitHub, пути ZIP и результаты проверок относятся к тому этапу. Текущая версия 0.3.2 и правила поставки — specifications/CURRENT_STATE.md и WINDOWS_DISTRIBUTION.md.

# Firewall Compliance v0.3

Статус качества: предварительная версия с известными ограничениями.
Планируемый Git-тег: `v0.3`. Версия Python-пакета и приложения: `0.3.0`.

## Изменения, подготовленные в этой рабочей копии

### Интерфейс инфраструктуры

- Временно скрыта правая панель с вкладками «Сведения», «Правила», «Объекты»,
  «Проблемы», «История» и «Источники».
- Таблица ресурсов занимает освободившееся место.
- Подключение панели к видимому макету закомментировано; её модели и обработчики
  сохранены для совместимости и возможности вернуть панель.
- Данные, результаты проверок и остальные разделы не удаляются.

### Инженерный Harness

- Добавлены инструкции Codex, цели, планы и компактный контекст проекта.
- Добавлены единые команды установки, проверки качества, тестирования, CLI/Qt
  smoke, сборки Python-пакетов и проверки зависимостей / статических предупреждений.
- Добавлены карта статических импортов, оценка влияния изменений и контроль
  границ domain / analysis / parsers.
- Добавлены четыре локальных Skills и конфигурация CI для Linux / Windows.
- Инструменты Harness закреплены отдельным lock-файлом; результаты запусков
  сохраняются в отдельных каталогах артефактов.

### Планирование

- Зафиксирован продуктовый бэклог: матрица инфраструктуры, компактный обзор,
  анализ правил Cloud.ru и их представление на карте.
- Эти записи являются планами. Новая матрица, новый обзор и анализ облачных
  правил этим релизным изменением не реализованы.

## Включены свежие изменения main

Релизная ветка объединена с main 2924860, включая ранее загруженные изменения:

- Автоматический выбор совместимой версии API VMware Cloud Director через
  GET /api/versions до передачи ключа.
- Более понятная диагностика DNS / TLS / прокси / сетевых ошибок.
- Представление полученных облачных правил в разделе «Правила и объекты».
- Это получение и просмотр правил; проверки безопасности облачных правил
  по задаче CLOUD-001 пока не реализованы.

## Проверки и ограничения

- После объединения прошла отдельная offscreen-проверка версии 0.3.0, CLI JSON
  с находками, сохранения анализа, выбора устройства и скрытой панели. Панель
  проблем на своём экране остаётся видимой.
- Locked setup, архитектурная проверка, два теста Harness и сборка Python
  wheel / sdist прошли.
- В main ранее исключены tests, fixtures и часть smoke-скриптов. Это изменение
  перенесено из main; прежние тесты доступны в истории Git (например, c97c8a0).
  Полный Harness сообщает об отсутствии тестовых входов / скриптов и не проходит.
  Восстановление и адаптация тестового контура — отдельная незавершённая задача.
- Сохраняются ошибки Ruff / mypy, предупреждения Bandit и advisory для pytest
  8.4.2. Релиз нельзя описывать как прошедший полный quality gate.
- Native Windows EXE / portable ZIP в этой Linux-среде не собраны и не проверены.
  Локальные Python-пакеты не заменяют Windows portable-приложение.

## Публикация

Git-доступ к ветке release/v0.3 работает; исходная ошибка авторизации оказалась
не окончательным запретом push. Прямые запросы GitHub Releases API по-прежнему
возвращают Forbidden. Для страницы релиза / загрузки assets требуется восстановить
API-доступ: проверить полномочия GitHub и сетевые разрешения api.github.com /
uploads.github.com. Сохранённые release notes можно использовать при публикации.
