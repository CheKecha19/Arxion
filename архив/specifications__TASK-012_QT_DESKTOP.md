# TASK-012: Qt desktop, проекты и отчёты по запуску

## Цель

Предоставить локальный путь «проект → папка → анализ → сводка → HTML/JSON»
с историей между запусками и тёмным интерфейсом Qt.

## Контекст

Утверждённый пользователем план нового desktop. ADR-018, ARCHITECTURE,
DEVELOPMENT_RULES; FR-001, FR-003, FR-005, FR-021, FR-022, FR-030.
Ограничения анализа из SUPPORTED_PLATFORMS и SR-005 сохраняются.

## Область задачи

- PySide6 / Qt Widgets, модели таблиц, поиск, панель доказательств и история.
- Пакетный импорт, независимая диагностика файлов, очередь Python worker.
- SQLite-проекты, исходные результаты и отдельные пользовательские отметки.
- Автономный HTML, версионированный JSON-пакет, Windows portable сборка.
- Перенос существующих ASA network/forwarding инструментов и актуализация гайдов.

## Вне области задачи

- Новые parser/platform semantics, Juniper и controller ACL.
- Итоговая достижимость, NAT/PBR evaluator, автоматическое исправление устройств.
- Хранение полных исходников, автоматическая замена чувствительных данных.
- Автоматическое признание находки устранённой или перенос статусов между снимками.

## Критерии приёмки

- Длинная очередь не блокирует окно; ошибка файла не прерывает остальные задания.
- История, выдержки, настройки и отметки сохраняются после перезапуска.
- Другой SHA-256 не может стать доказательством старого запуска.
- HTML не использует внешние ресурсы, экранирует исходные значения; JSON сохраняет
  модели ядра и отдельно описывает пользовательские решения.
- Проверены таблицы/поиск/клавиатура, закрытие во время работы и packaged запуск.
- Существующие core/CLI проверки проходят; ограничения отражены в UI и отчётах.

## Проверка

- Unit/integration: Qt proxy mapping и контраст, storage/export contracts.
- Оконный smoke: `scripts/qt_desktop_smoke.py`, synthetic fixtures и temporary БД.
- Сборка: отдельный запуск bundled executable; чистые ОС не предполагаются проверенными
  без отдельного подтверждённого испытания.

## Безопасность и обработка данных

БД содержит нормализованный инвентарь и доказательства, потенциально чувствительные
значения. Полные конфигурации не сохраняются. Первичные source bytes живут в памяти;
восстановление требует исходника с совпадающим SHA-256. Реальные конфигурации не
копируются в fixtures, smoke или артефакты. Пользовательские отчёты сохраняются явно.

## Зависимости и риски

PySide6 и PyInstaller увеличивают размер portable поставки. Frozen запуск и чистая
Windows-матрица — разные уровни валидации. Ядро не поддерживает кооперативную отмену
выполняющегося анализа, поэтому отменяются только ожидающие задания.

## Запись о завершении

Qt, проекты и отчёты реализованы. Полный pytest: 1230 passed; Ruff и mypy (67 source files) успешны. Native Qt smoke: 80 synthetic файлов, отдельный масштаб 150%, реальные network forms; все процессы exit0. Frozen executable прошёл self-test с очищенным PATH, без запуска внешнего Python (frozen=true, exit0). Подробности и предел испытаний Windows — в CURRENT_STATE.
Контракты ядра/CLI сохраняются. JSON desktop-пакета версионируется отдельно.
