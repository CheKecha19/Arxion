# TASK-013 — Компоновка Qt-меню и дашборда

Дата: 11.10.2026.
Статус: завершена.

## Цель

Применить согласованную пользователем структуру меню, сохранив функции импорта,
анализа, истории, пользовательских решений, сетевых API и экспорта.

## Контекст и область задачи

Основание — согласованная в чате компоновка; архитектурная основа ADR-018,
[ARCHITECTURE.md](ARCHITECTURE.md), [DEVELOPMENT_RULES.md](DEVELOPMENT_RULES.md).
Затронуты desktop-сценарии TASK-012; аналитические границы TASK-008 не расширяются.
Изменения относятся к навигации, представлению и чтению накопительного инвентаря.

## Вне области задачи

Новые парсеры, проверки, достижимость и построение карты. Объявленные ранее
ограничения анализа остаются в силе.

## Критерии приёмки

- Все прежние страницы и действия доступны через согласованное меню.
- Главная показывает весь проект; выбранный исторический запуск её не подменяет.
- Анализ не переключает текущую страницу; уведомление даёт явный переход.
- Настройки сохраняются между проектами/перезапусками; импорт, отчёты и история
  работают с теми же backend-контрактами.
- Проверены большие пакеты, клавиатура, масштабы 100–150% и сборка.

## Изменения

- «Главная» открывает дашборд; её подменю содержит устройства, историю и отчёты.
- «Аналитика» раскрывает карту, находки, правила/объекты и расширенный анализ.
- Настройки закреплены отдельной кнопкой внизу; параметры сохраняются сразу.
- Подготовка файлов перенесена в устройства, запуск — в общую шапку.
- Главная считает все уникальные device_id проекта по последним разобранным снимкам.
  Ошибки файлов не создают фиктивные устройства; частичные снимки учитываются явно.
- Карточка устройства содержит сведения, правила и объекты; глобальный поиск правил
  доступен по всем устройствам проекта либо выбранному запуску.
- Завершение анализа сохраняет текущую страницу и показывает уведомление с итогом
  и переходом на главную. Дополнительных modal-диалогов завершения нет.
- Будущий раздел карты явно сообщает, что карта ещё не реализована.

## Совместимость

Схема SQLite не изменена. Исходные результаты анализатора и пользовательские
решения остаются раздельными. Существующие report contracts, worker, отмена,
проверка SHA-256, CLI и network APIs сохранены.

## Проверки

- Полный pytest: 1239 passed.
- Ruff check и mypy: успешно; проверены 67 source files.
- Новые регрессии: группы меню, принадлежность controls странице, все устройства
  без дублей, дата последней проверки при просмотре истории, области rules,
  вкладки устройства и сохранение страницы после частичного анализа.
- Оконные проверки: 80 synthetic файлов, клавиатура, сохранение страницы,
  история, exports, hash и закрытие worker; масштабы 100% и 150%.
- Регрессия обнаруженной при просмотре ошибки: событие RUNNING из того же poll

## Безопасность, зависимости и риски

В тестах используются только synthetic fixtures и отдельные SQLite-базы.
Полные конфигурации не добавляются в хранилище; raw данные не выводятся в логи.
Новых зависимостей и изменений схем нет. Пакетный анализ сохраняет ограничения
своего worker; чистая матрица Windows 10/11 остаётся отдельным релизным критерием.
