# UserGate NGFW

Статус: не выбран для первого production-quality парсера.

Официальный текстовый экспорт UserGate NGFW 7.5+ отличается от двух legacy JSON fixtures. Поэтому JSON-файлы остаются в `tests/fixtures/legacy/` только как поведенческий ориентир и не переносятся в этот каталог.

Повторная оценка допускается после получения минимум трёх законных обезличенных экспортов с установленной версией. Для каждого файла обязательны SHA-256, сценарий, версия и источник.
