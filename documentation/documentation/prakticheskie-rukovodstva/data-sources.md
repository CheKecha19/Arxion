# Источники данных

Arxion работает с конфигурационными файлами и снимками, полученными через поддержанные API. Источник определяет, откуда приложение получает сведения; результат проверки относится к конкретным полученным данным, а не к непрерывно наблюдаемому состоянию оборудования.

Для начала выберите проект. Подготовьте экспорт конфигурации либо настройте подключение к источнику. После получения данных проверьте распознанную платформу, связь с устройством и предупреждения о полноте. Только затем переходите к выводам анализа.

## Импорт конфигурационных файлов

Используйте текстовый экспорт поддержанной платформы. Для UserGate и Ideco требуется JSON-снимок собственного коллектора Arxion: произвольная резервная копия производителя не является эквивалентным входом.

1. Откройте **«Источники данных → Файлы и запуск»**.
2. Нажмите **«Добавить файлы»** или **«Добавить папку»**.
3. Проверьте таблицу с колонками **«Файл»**, **«Формат»**, **«Устройство»**, **«Состояние / предупреждение»**.
4. При необходимости дважды щёлкните строку, чтобы изменить связь файла с устройством.
5. Выполните проверку и изучите отдельно результаты и диагностику импорта.

Формат определяется по содержимому. Переименование файла или смена его расширения не превращает неподдержанный экспорт в поддержанный.

**«Убрать выбранные»** и **«Очистить список»** управляют подготовленным списком. Не следует путать подготовку файлов с удалением истории проекта.

## Повторное использование файлов

Для регулярных проверок нажмите **«Сохранённые источники…»**.

* **«Новый набор…»** сохраняет выбранные пути к файлам.
* **«Новая папка…»** сохраняет путь к папке.
* **«Сохранить подготовленные…»** создаёт источник из уже подготовленных файлов.
* **«Изменить…»** позволяет изменить существующий источник.

Задайте понятное название, например `Лаборатория — коммутаторы`, и отметьте **«Включать в „Обновить и проверить“»**, если источник должен участвовать в общем цикле.

Для набора файлов доступны **«Добавить файлы…»**, **«Исключить выбранный»**, **«Связать с устройством…»**. Для папки используется **«Выбрать папку…»**.

Сохраняются пути, а не неизменяемая копия содержимого. При следующем запуске Arxion прочитает текущие файлы. Содержимое папки перечитывается при каждом запуске; вложенные папки не включаются.

Например, сохраните набор из `C:\ArxionDemo\switch-a.cfg` и `C:\ArxionDemo\switch-b.cfg`. После обновления экспортов по этим же путям повторный цикл обработает новое содержимое. Если файлы перемещены, исправьте источник.

## Общий цикл

**«Обновить и проверить»** запускает обработку сохранённых источников. Сбор и анализ — разные этапы: успешное получение данных ещё не означает, что все содержащиеся правила были проанализированы.

Следите за состоянием отдельных операций. Ошибка одного источника не означает, что результаты остальных потеряны. При частичном результате сначала разберите диагностику, затем оценивайте находки.

Резкое сокращение количества правил или ресурсов требует проверки состава входных данных. Оно может быть связано с реальным изменением инфраструктуры, правами подключения или неполным экспортом; само по себе оно не доказывает улучшение безопасности.
