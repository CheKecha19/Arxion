# Карты

Карты показывают разные виды сведений. Перед интерпретацией связи убедитесь, какой режим выбран.

| Режим         | Содержание                                                      |
| ------------- | --------------------------------------------------------------- |
| ACL ревизии   | Условия правил выбранного снимка и ссылки на их источники       |
| Топология     | Интерфейсы устройства и привязанные к ним подсети               |
| Карта проекта | Ресурсы проекта, структура и условия правил между ними          |
| Коммутаторы   | Порты, VLAN, агрегаты и сведения о соседях с основаниями связей |

## Работа с картой

1. Откройте карту инфраструктуры.
2. Выберите режим.
3. Через «Источники…» уточните используемые данные и выбранный результат.
4. Выберите элемент карты, чтобы просмотреть его свойства и происхождение.
5. Используйте масштабирование и «Вписать» для удобного просмотра.

В режиме топологии доступны фильтры «Все интерфейсы», «С подсетями» и «Без привязок подсетей». В карте проекта можно переключаться между «Структура сети» и «Условия правил», открывать «Свойства», «Правила» и «Доступ».

Одинаковые IP-адреса разных адресных областей не должны считаться одним ресурсом. Совпадение VLAN или подсети само по себе не подтверждает физическое соединение устройств.

## Карта ACL

Для анализа конкретного обмена задайте адресные и сервисные фильтры и нажмите «Применить фильтры». «Сбросить» снимает их. Правила с неизвестными условиями требуют отдельного рассмотрения.

«Все правила» возвращает общий просмотр; «Назад» возвращает предыдущий фокус. Кнопки «Экспорт HTML» и «Экспорт PNG» позволяют сохранить представление карты.

Сохранённые и пакетные карты открываются через «Сохранённые карты…». Архивная карта относится к определённой ревизии и не обновляется автоматически при изменении конфигурации.

Линия на ACL-карте означает заданное условие правила, а не подтверждённую сетевую достижимость. Настроенный интерфейс не доказывает состояние link up, а настроенный маршрут — его присутствие в рабочей таблице маршрутизации.
