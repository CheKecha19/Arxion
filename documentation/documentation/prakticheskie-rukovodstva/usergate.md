# UserGate

Интеграция получает данные API и сохраняет снимок `arxion-usergate-v1`, который затем обрабатывается обычным анализом. Операции чтения не изменяют конфигурацию устройства, но вход и выход из API могут отражаться в журнале устройства.

## Подготовка

Потребуются адрес устройства, доступная сеть управления, учётная запись с необходимыми правами чтения API и включённый API-доступ на UserGate. Для HTTPS с внутренним центром сертификации подготовьте PEM-файл доверенного CA.

Поддержанные профили подключения:

| Профиль                 | Назначение                         |
| ----------------------- | ---------------------------------- |
| UserGate 6 · TCP/HTTP   | Ветка UGOS 6 начиная с 6.1.5       |
| UserGate 7 · TCP/HTTP   | UGOS 7 через HTTP                  |
| UserGate 7.3.3+ · HTTPS | HTTPS для соответствующих выпусков |

Название TCP/HTTP в интерфейсе означает XML-RPC поверх HTTP. Порт по умолчанию — 4040 для HTTP и 4443 для HTTPS; используется путь `/rpc`. Поле адреса принимает имя узла или IPv4 без `https://`, пути и номера порта. Порт указывается отдельно.

HTTP используйте только в защищённой сети управления. Для HTTPS Arxion проверяет сертификат; автоматического перехода на HTTP и режима отключения проверки TLS нет. Версия, сообщённая устройством после входа, должна соответствовать выбранному профилю.

## Настройка и получение данных

1. Откройте **«Настройки → Интеграции»** и выберите UserGate.
2. В поле **«Сохранённый источник»** выберите **«Новое подключение»**.
3. Заполните **«Название»**, **«Адрес узла»**, **«Пользователь»**, **«Пароль»**.
4. Выберите **«Профиль»**. При необходимости задайте **«Порт»**, **«Таймаут, с»**, **«PEM CA»**.
5. Для повторных автоматических проверок отметьте **«Сохранить подключение и защищённый пароль для повторных проверок»** и нажмите **«Сохранить подключение»**.
6. Нажмите **«Прочитать конфигурацию»** для получения снимка.
7. Проверьте результат операции и добавленный к анализу файл на странице **«Источники данных → Файлы и запуск»**.

Можно сохранить несколько именованных подключений. Используйте названия, позволяющие отличить устройства, например `UserGate — лаборатория` и `UserGate — филиал`.

Пароль для повторного использования защищается Windows DPAPI. Сохранённый секрет привязан к конфигурации подключения; изменение адреса или других параметров может потребовать повторного ввода.

## Границы анализа

Arxion разбирает ограниченный набор правил, статических адресов, сервисов и зон. Динамические группы, пользовательские и прикладные условия, расписания и security profiles могут сделать вывод частичным или неизвестным.

NAT сохраняется отдельно; полноценная трансляция адресов не вычисляется. API-снимок собирается несколькими запросами и не является атомарным состоянием устройства на одну точную секунду. Совместимость со всеми прошивками не подтверждена.

## Если сбор не выполнен

Проверьте профиль версии, адрес и порт, включение API, права пользователя и сетевую доступность. Для HTTPS проверьте сертификат и PEM CA. После устранения причины получите новый снимок; частичный файл не следует считать полным экспортом.

Сообщение об изменении списка во время чтения означает, что коллектор обнаружил повтор идентификатора при постраничном получении. Повторите сбор после завершения изменений на устройстве. Лимит размера или числа страниц не следует обходить редактированием снимка: такой результат нельзя выдавать за полный.
