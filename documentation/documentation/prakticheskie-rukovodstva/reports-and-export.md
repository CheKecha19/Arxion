# Отчёты и экспорт

Arxion предоставляет несколько самостоятельных видов результатов:

| Результат                           | Назначение                                                        |
| ----------------------------------- | ----------------------------------------------------------------- |
| Общий результат анализа             | Снимки входных данных, параметры, выводы и ограничения            |
| Сверка матрицы                      | Соответствие конкретной версии требований выбранной ревизии       |
| Каталог коммутатора или контроллера | Извлечённая структура и политики устройства                       |
| Карта ACL                           | Условия правил и их связи                                         |
| Оценка технических контролей        | Технические свидетельства для явно выбранного профиля организации |
| Governance-оценка                   | Анализ метаданных и статистики правил сохранённого компонента     |

Перед экспортом проверьте проект, запуск/снимок, время получения данных, параметры и полноту результата. Текущий визуальный фильтр не следует автоматически считать областью всего экспортируемого отчёта.

Для общего результата выберите сохранённый результат и нужный формат — JSON, CSV или HTML. JSON предназначен в том числе для последующей обработки приложением; HTML удобен для чтения; CSV — для табличной обработки.

Экспорт исторического общего результата не перечитывает исходную конфигурацию и не выполняет проверки заново. Если сохранённый результат не проходит проверку формата и целостности, экспорт недоступен: это не следует обходить ручным удалением непонятных полей.

Для матрицы используйте собственные кнопки экспорта. Для карты ACL доступны отдельные форматы; PNG доступен в GUI, а CLI экспортирует JSON, DOT и HTML.

Технические контроли формируют ограниченные свидетельства. Они не являются автоматическим заключением о полном соответствии организации внешнему стандарту.
