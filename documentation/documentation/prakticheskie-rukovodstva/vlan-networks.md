# VLAN и логические сети

VLAN-наблюдение — сведения из конфигурации конкретного устройства. Логическая сеть — описанная пользователем ожидаемая сеть, к которой можно привязать наблюдения.

Одинаковый VLAN ID на двух устройствах не доказывает, что они образуют одну сеть.

## Просмотр обнаруженных VLAN

Откройте **«Инфраструктура → Ресурсы и VLAN»**, затем **«Реестр VLAN»**, вкладку **«Обнаруженные VLAN»**.

Изучите устройство, номер VLAN, название, подсети, IP-интерфейсы, подключения портов и источник. Типы access/untagged/tagged/trunk отражают конфигурацию. Они не подтверждают состояние link up или фактическую передачу трафика. IP интерфейса не автоматически объявляется шлюзом.

## Создание логической сети

На вкладке **«Логические сети»** нажмите **«Добавить сеть»** и заполните:

| Поле              | Пример                            |
| ----------------- | --------------------------------- |
| Название          | Лаборатория                       |
| Площадка          | Учебная площадка                  |
| Ожидаемый VLAN ID | 100                               |
| Ожидаемые подсети | `192.0.2.0/24, 2001:db8:100::/64` |
| VRF               | `lab`, если используется          |

Допустимый VLAN ID — 1–4094. Подсети вводятся в CIDR, через пробелы или запятые. VRF сохраняется как атрибут логической сети.

Другой способ — выбрать обнаруженный VLAN и нажать **«Создать логическую сеть»**. Приложение использует наблюдение как исходные данные формы; проверьте их перед сохранением.

## Подтверждение привязок

Совпадение площадки и VLAN ID формирует предложение, а не автоматическое доказательство принадлежности.

1. Выберите логическую сеть.
2. Нажмите **«Подтвердить предложенные VLAN»**.
3. Сравните устройства, обнаруженные подсети, результаты сопоставления и источники.
4. Отметьте только нужные VLAN и нажмите **«Подтвердить привязки»**.

Для отдельного наблюдения доступна **«Изменить привязку»**. Значение **«Без привязки»** снимает связь. Изменения можно просмотреть через **«История правок»**.

## Сравнение подсетей

Arxion сопоставляет ожидаемые подсети логической сети с известными IP-префиксами привязанного VLAN из последней сохранённой ревизии. Неожиданный префикс показывается как расхождение со ссылкой на источник.

Если нет IP-интерфейса, ожидаемого списка либо достаточных адресных данных, результат может быть **«Нет данных для сравнения»**. Это не подтверждение соответствия.

Старые ревизии без VLAN-данных не обогащаются автоматически. Для получения новых сведений повторно импортируйте конфигурацию.
