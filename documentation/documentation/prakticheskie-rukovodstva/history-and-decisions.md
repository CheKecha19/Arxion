# История и решения по находкам

## Решение пользователя

Решение — отдельная отметка к находке сохранённого запуска. Оно не изменяет исходное заключение анализатора и не исправляет конфигурацию устройства.

1. Выберите одну или несколько находок.
2. Откройте вкладку «Решение».
3. Выберите статус и заполните «Комментарий к выбранным находкам».
4. Нажмите «Применить к выбранным».

Один выбранный статус и комментарий применяются ко всему выделению. Перед массовым действием проверьте список.

| Статус                           | Как использовать                                                            |
| -------------------------------- | --------------------------------------------------------------------------- |
| Новая                            | Находка ещё не разобрана или возвращена к рассмотрению.                     |
| Подтверждена                     | Пользователь подтвердил значимость результата.                              |
| В работе                         | Запланировано или выполняется действие по находке.                          |
| Риск принят                      | Зафиксировано решение сохранить состояние с обоснованием.                   |
| Ложное срабатывание              | Пользователь считает вывод неприменимым и документирует причину.            |
| Устранена (решение пользователя) | Ручное решение; само по себе не доказывает устранение в новой конфигурации. |

Для подтверждения исправления получите новую конфигурацию и выполните сопоставимую проверку. Укажите в комментарии основание решения, нужную задачу или согласование без секретов. Статус не заменяет организационную процедуру принятия риска.

## Доказательства и журнал

Во вкладке «Доказательство» доступны действия «Открыть связанные правила», «Подключить исходник», «Технический JSON». При подключении исходного файла проверяется SHA-256, чтобы строки относились к сохранённой конфигурации. Технический JSON показывает находку и сведения о проверке.

«История решений» открывает журнал для первой выбранной находки: исходное состояние, время изменений, прежний и новый статусы, прежний и новый комментарии. Для старых записей может быть известно только последнее решение до включения журнала: более ранние переходы не восстанавливаются догадками. Если после включения журнала изменений не было, это указано отдельно.

## Сравнение запусков

Сравнение помогает увидеть изменения состава устройств, правил, сетевых данных и результатов. Перед трактовкой проверьте одинаковую идентичность устройств и области входов, сопоставимость профилей, полноту обеих ревизий и версии разбора. Изменение условий не доказывает открытие или закрытие сквозного доступа.

Если данные исчезли из нового сбора, это не доказывает удаление ресурса или устранение проблемы. Отключение проверки и смена профиля могут уменьшить число находок без улучшения безопасности. Сравниваются сохранённые ревизии, а не гарантированно одновременный снимок всей инфраструктуры.

## Перенос решений

Статусы и комментарии не переносятся между запусками автоматически. Не считайте похожую находку уже согласованной только потому, что решение было принято в предыдущем запуске. Изучите идентичность, доказательства, изменившиеся условия и профиль; при необходимости сохраните новое обоснованное решение. Сравнение само по себе не изменяет отметки.

## Если история или сравнение недоступны

Убедитесь, что выбран проект, сохранённый запуск и находка. Ошибка чтения журнала не означает отсутствие событий. Для несопоставимых запусков изучите профили, состав источников и основание идентичности устройств, а не сводите вывод к количеству появившихся и исчезнувших проблем.
