# Интерфейс и навигация

Описана навигация рабочего дерева 0.13.0. В опубликованной 0.10.0 часть инструментов расположена внутри раздела проверок.

## Верхняя панель

**Проект** выбирает набор данных. **Новый проект** создаёт отдельную область работы. **Область просмотра** фильтрует сведения по площадкам; **Площадки** открывает назначения. **Добавить данные** подготавливает входы; **Обновить и проверить** запускает согласованный цикл обработки; **Задачи** показывает активные операции и историю.

При переключении проекта дождитесь окончания загрузки. Не воспринимайте временно пустую таблицу или заблокированную кнопку как потерю данных.

## Разделы

| Раздел                            | Для чего нужен                                                         |
| --------------------------------- | ---------------------------------------------------------------------- |
| Обзор                             | Показатели, распределение критичности, динамика и состояние источников |
| Анализ → Проверки                 | Находки, доказательства и решения                                      |
| Анализ → История и изменения      | Сохранённые запуски и сравнение результатов                            |
| Инфраструктура → Ресурсы и VLAN   | Устройства, наблюдения, VLAN и логические сети                         |
| Инфраструктура → Карта сети       | Карты и связи                                                          |
| Доступ → Правила                  | Правила и объекты, фильтрация и переход к источнику                    |
| Доступ → Матрица доступа          | Требования доступа и их сопоставление со снимком                       |
| Доступ → Сетевые инструменты      | Дополнительные запросы к сетевой модели                                |
| Отчёты                            | Экспорт результатов                                                    |
| Источники данных → Файлы и запуск | Подготовка и запуск файлового анализа                                  |
| Источники данных → Облачный сбор  | Сбор и просмотр облачных данных                                        |
| Настройки → Интеграции            | Сохранённые подключения                                                |
| Настройки → Проверки              | Выбор проверок и организационные требования                            |

**Общие**, **Лицензия** и **Документация** в дереве настроек пока неактивны. Наличие подписи не означает реализованную настройку.

## Возврат и фильтры

Кнопка **← Назад** и **Alt+Left** возвращают к предыдущему контексту просмотра. Перед экспортом и сравнением проверяйте проект, площадку, выбранный запуск и фильтры. Видимая выборка таблицы и область полного отчёта могут различаться.

## Дашборд

Число находок оценивается вместе с полнотой, составом устройств и профилем. Снижение счётчика после неполного сбора не доказывает улучшения безопасности. Разрывы линии динамики обозначают отсутствие сопоставимого наблюдения. В карточках источников различаются последняя попытка и успешный сбор; старый успех не подтверждает текущую доступность API.

## Задачи и отмена

**Отменить ожидающие** запрашивает остановку между элементами. Текущий парсер или API-запрос не обязаны прерваться немедленно. Уже сохранённые результаты остаются. Перед закрытием приложения дождитесь завершения: закрытие окна не гарантирует завершения фоновой операции или её последующего автоматического восстановления.
