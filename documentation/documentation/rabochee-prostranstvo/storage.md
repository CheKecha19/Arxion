# Хранение, защита и восстановление

## Где находятся данные

Стандартная база рабочего места:

```
%LOCALAPPDATA%\FirewallCompliance\projects.sqlite3
```

В ней сохраняются проекты, нормализованные снимки, результаты, история и пользовательские решения. Полный исходный файл автоматически в базу не копируется. Для полного просмотра доказательства и повторного разбора храните исходные экспорты отдельно.

Приложение сверяет SHA-256 исходника: файл с другим содержимым не может служить доказательством прежней ревизии. Если файл перемещён, подключите неизменную копию при запросе приложения. Если файл изменён, выполните новый импорт.

## Секреты и доступ

Сохранённые секреты интеграций защищаются Windows DPAPI в контексте пользователя. Перенос базы на другой компьютер или под другую учётную запись не гарантирует расшифровку: потребуется повторно ввести секреты.

DPAPI для секретов не означает шифрование всей базы. База, конфигурации и отчёты могут содержать адреса, имена, правила и фрагменты конфигурации. Ограничивайте доступ средствами Windows и используемого хранилища. Проекты внутри приложения не создают отдельные системные учётные записи или роли доступа.

Для интеграций используйте права на чтение необходимой области API. Не включайте пароли, токены, приватные ключи и исходные клиентские конфигурации в обращения за помощью.

## Резервное копирование

1. Дождитесь окончания задач и закройте все экземпляры приложения.
2. Скопируйте базу в защищённый каталог резервных копий. Если рядом присутствуют служебные файлы SQLite, сохраняйте согласованный комплект после завершения приложения; не копируйте работающую базу по частям.
3. Отдельно сохраните исходные конфигурации, важные экспорты, сведения о версии программы и времени копирования.
4. Храните копию независимо от каталога дистрибутива.

Некоторые первые записи новых метаданных создают рядом с базой файлы вида `projects.sqlite3.before-sites-…sqlite3`, `before-profiles-…` или `before-matrices-…`. Это копии перед конкретным изменением структуры, а не регулярная резервная система.

## Восстановление

Закройте приложение, сохраните текущую базу отдельно, затем восстановите совместимую резервную копию на стандартное место. Запустите соответствующую версию приложения и проверьте проект и историю. Если секреты недоступны, сохраните их заново в настройках интеграции. Исходные файлы подключите отдельно.

При откате после обновления восстанавливайте и подходящую копию данных. Автоматическое обратное преобразование новой схемы в старую не обещается.

## Перенос рабочего места

Переносите полную папку поставки, базу и необходимые исходники. Сам перенос EXE не переносит проекты из пользовательского профиля. Изменившиеся пути к конфигурациям потребуют повторного выбора файлов; идентичность подтверждается содержимым, а не одним именем файла.
