# Справочник проверок управления

В исходниках Arxion 0.13.0 определены 12 проверок управления. Они опираются на извлечённые настройки и не подключаются к службам для проверки работоспособности.

При отсутствии модели управления появляется MANAGEMENT\_UNSUPPORTED. Неполный экспорт не доказывает отсутствие настройки. Неподдержанный или противоречивый синтаксис соответствующей области откладывает вывод. Заводские значения не предполагаются. Все находки ниже имеют среднюю критичность, кроме баннера — низкой.

## MGMT-TELNET

Явно включён Telnet. Проверьте необходимость и переведите управление на SSH. Неизвестное состояние не равно выключенному Telnet; доступность порта не проверяется.

## MGMT-HTTP

Явно включён HTTP для управления. Используйте HTTPS после проверки зависимостей. Строка настройки не доказывает доступность веб-интерфейса.

## MGMT-ADMIN-SOURCES

Источники управления выходят за объединение `approved_admin_networks`. Результат содержит адрес за пределами разрешённых сетей. Уточните утверждённый перечень и сузьте источники. Незаданный список не позволяет оценку; пустой список не разрешает никаких источников.

## MGMT-IDLE-TIMEOUT

Тайм-аут равен нулю или больше `max_idle_seconds`; исходное значение профиля — 900 секунд. Задайте ненулевой тайм-аут в пределах требований. Отсутствующая явная настройка не заменяется заводским значением.

## MGMT-BANNER

При `require_banner=true` баннер отсутствует в полном экспорте либо имеется явный отрицательный факт. Настройте утверждённый непустой баннер. Низкая критичность; содержание текста не оценивается.

## MGMT-SNMP-LEGACY

Обнаружен явный факт устаревшей настройки SNMP. Пересмотрите использование старых версий и возможность перехода на SNMPv3 с подходящей защитой. Реальная доступность SNMP не проверяется.

## MGMT-SNMP-WRITE

Разрешена запись SNMP при `allow_snmp_write=false`. Уберите ненужную запись либо согласуйте требование. Разрешение записи профилем отключает это требование, а не подтверждает безопасность SNMP в целом.

## MGMT-SNMP-SOURCES

Настроенные источники выходят за `approved_snmp_networks`. Ограничьте доступ сетями мониторинга и проверьте показанное основание. Пустой и незаданный списки различаются.

## MGMT-SYSLOG-MISSING

При `require_syslog=true` в полном экспорте отсутствуют серверы. Настройте внешний сбор журналов. Для неполного экспорта сначала получите полные данные; доставка событий не измеряется.

## MGMT-SYSLOG-UNAPPROVED

Настроенный сервер не входит в `approved_syslog_servers`. Сверьте получателя с утверждённым списком. Сопоставляются нормализованные IP/DNS-имена без сетевого разрешения DNS.

## MGMT-NTP-MISSING

При `require_ntp=true` NTP отсутствует в полном экспорте. Настройте согласованный источник времени. Наличие настройки не подтверждает синхронизацию часов.

## MGMT-NTP-UNAPPROVED

Настроенный сервер не входит в `approved_ntp_servers`. Исправьте сервер либо уточните список. Эквивалентность DNS-имени и IP автоматически не устанавливается.

## Интерпретация общего результата

Отсутствие явных фактов для большинства проверок даёт MANAGEMENT\_FACTS\_UNKNOWN, а не успешный вывод по заводским значениям. Незаданный разрешённый список даёт MANAGEMENT\_PROFILE\_REQUIRED. Неполнота экспорта сопровождается MANAGEMENT\_EXPORT\_INCOMPLETE. Отключённые требования Syslog, NTP, баннера или запрета SNMP write сопровождаются CHECK\_NOT\_EXECUTED. Смотрите фактический статус и ограничения каждой проверки, а не только итоговое число находок.
