# Термины и обозначения

| Термин                      | Значение в Arxion                                                                                  |
| --------------------------- | -------------------------------------------------------------------------------------------------- |
| Проект                      | Область настроек, источников, ресурсов и истории локального анализа                                |
| Площадка                    | Явно заданное размещение устройств внутри проекта                                                  |
| Источник                    | Файл или настроенное подключение, из которого получены сведения                                    |
| Сбор                        | Получение данных через интеграцию; само по себе не означает выполнение проверок                    |
| Импорт / разбор             | Преобразование конфигурации в поддержанную модель с диагностикой                                   |
| Ревизия / снимок            | Сохранённое состояние данных устройства для последующего анализа                                   |
| Запуск                      | Операция анализа конкретного состава входов с выбранными настройками                               |
| Профиль проверки            | Настройки требований и выбранных проверок                                                          |
| Находка / finding           | Выявленная проверкой проблема, требующая интерпретации                                             |
| Критичность / severity      | Уровень важности находки; не степень полноты анализа                                               |
| Доказательство / evidence   | Правило, объект, строки и другие сведения, на которых основан вывод                                |
| Происхождение / provenance  | Связь результата с источником и контекстом получения                                               |
| SHA-256                     | Отпечаток содержимого файла, используемый для проверки его идентичности                            |
| ACL                         | Список правил контроля доступа                                                                     |
| ACE                         | Отдельная запись ACL                                                                               |
| Применение ACL / attachment | Привязка объявления ACL к интерфейсу, направлению или иному контексту                              |
| Management plane            | Управление самим устройством; отличается от транзитной фильтрации                                  |
| ANY                         | Явное отсутствие ограничения соответствующего поля правила; не замена неизвестному значению        |
| Shadowing / затенение       | Ситуация, когда более ранние правила перекрывают область последующего правила                      |
| VLAN                        | Идентификатор виртуальной локальной сети в контексте устройства                                    |
| Логическая сеть             | Заданная пользователем сущность с ожидаемыми VLAN и подсетями                                      |
| CIDR                        | Запись IP-префикса, например 192.0.2.0/24                                                          |
| VRF                         | Контекст маршрутизации; совпадающие адреса в разных контекстах не следует автоматически объединять |
| VDC                         | Контекст виртуального дата-центра в облачной инфраструктуре                                        |
| Матрица доступа             | Согласованные требования к сочетаниям источника, назначения и сервиса                              |
| Сервис                      | Протокол и, когда применимо, порты                                                                 |
| NAT                         | Преобразование адресов; наличие объявления не гарантирует вычисления полной трансляции             |
| PBR                         | Маршрутизация на основе политики                                                                   |
| Effective-конфигурация      | Экспорт применяемой конфигурации с учётом наследования; особенно важен для контроллеров            |
| Complete                    | Полнота в рамках заявленного контракта, а не универсальная полнота модели сети                     |
| Partial                     | Получены или поддержаны только некоторые данные                                                    |
| Unknown                     | Данных или семантики недостаточно для определённого вывода                                         |
| Unsupported                 | Конструкция или сценарий не поддержаны                                                             |
| Not applicable              | Проверка неприменима к данному входу                                                               |
| Локальное решение           | Решение в пределах конкретной политики и её известного контекста                                   |
| Сквозная достижимость       | Доступность по всему пути; требует сведений обо всех влияющих этапах                               |

Неизвестный результат нельзя читать как «запрещено» или «безопасно». Успешное завершение операции также не означает отсутствие находок.
