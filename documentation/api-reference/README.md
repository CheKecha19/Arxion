# Интерфейсы Arxion

В текущей реализации Arxion нет публичного серверного REST API. Демонстрационный Petstore API из шаблона GitBook не относится к приложению.

## Доступные способы работы

| Интерфейс         | Назначение                                                                    |
| ----------------- | ----------------------------------------------------------------------------- |
| Windows desktop   | Интерактивная работа с проектами, источниками, проверками и отчётами          |
| CLI из исходников | Анализ файлов, сбор поддержанных NGFW, карты, экспорт и дополнительные оценки |
| JSON-результаты   | Сохранение и последующая обработка структурированных результатов              |
| Интеграции        | Получение данных из поддержанных внешних API                                  |

API UserGate, Ideco и Cloud.ru являются внешними источниками. Их наличие не означает, что Arxion предоставляет собственный сетевой API.

## Пример обработки файла

В подготовленном окружении исходников:

```powershell
uv run firewall-compliance analyze-bundle "C:\ArxionDemo\device.cfg" -o "C:\ArxionDemo\analysis.json"
uv run firewall-compliance analysis-export "C:\ArxionDemo\analysis.json" -o "C:\ArxionDemo\analysis.html" --format html
```

Первый шаг сохраняет общий результат, второй экспортирует его без нового анализа. Нулевой код выхода не означает отсутствия находок: изучите статус полноты и содержимое результата.

Полный справочник команд и форматов размещён в [руководстве](https://app.gitbook.com/s/lo32lFq5iChWTEH1YNOx/). Не отправляйте конфигурации на демонстрационные endpoints из сторонних шаблонов.
