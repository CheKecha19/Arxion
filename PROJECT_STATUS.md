# Статус, roadmap и backlog

Единственный рабочий файл состояния проекта. Обновлён 01.11.2026; текущая версия исходников **0.8.0** (подготовка R3, приёмка CI открыта), база UI-работ `1a2b6df`. Исторические планы, требования и свидетельства сохранены в плоском корневом `архив` и не подменяют текущий статус. Новые отдельные roadmap/backlog/status/TASK-журналы не создавать.


Базовые возможности актуализированы 31.10.2026 по `c170560`; дополнения R1–R3 от 01.11.2026 описаны ниже. Версия исходников **0.8.0**.

## Реализовано в текущем приложении

- Qt desktop и CLI, проекты SQLite, история ревизий и решений по находкам, накопленный реестр инфраструктуры.
- Стандартный каталог: Cisco ASA, HP/Aruba, Comware, UserGate и Ideco. Поддержка экспериментальная и ограниченная; точные границы — [DOCUMENTATION](DOCUMENTATION.md).
- UserGate и Ideco: сбор через API с последующим анализом собственных JSON-снимков. Реальная совместимость прошивок не подтверждена.
- Cloud.ru VMware: сбор ресурсов и анализ NSX-T Edge Firewall; Advanced/Evolution — сбор инвентаря и Security Groups, без общего анализа SG.
- 27 определений проверок: 15 policy и 12 management. Выбор зависит от входных данных, профиля и сценария; наличие определения не означает выполнение для каждой платформы.
- Общий AnalysisResult, JSON/CSV/HTML; ACL-карта с фильтрами, архивом SQLite, CLI и экспортами JSON/DOT/HTML/PNG; технические контроли и governance-сценарии.
- Код платформ разнесён по `devices`, проверок — по `checks`; старые импорты сохранены. UserGate/Ideco пока находятся в `parsers`/`infrastructure`. AOS-Switch/AOS-CX используют общую грамматику вендора.
- Отложенный запуск Qt: окно до загрузки проекта, фоновое чтение, общий снимок истории и заполнение скрытых страниц по запросу. Количественное ускорение не измерено.
- Цель следующей сборки: `dist/FirewallComplience_v0.5.0` (ещё не создана); ZIP и отдельная CLI-поставка автоматически не создаются. См. [DEVELOPMENT](DEVELOPMENT.md).

## Ограничения и подтверждения

Полная сквозная достижимость, effective NAT/PBR, DFW и гостевые NGFW облака не подтверждены. ArubaOS controller имеет отдельный экспериментальный парсер, но не включён в стандартный каталог; Juniper не подключён. Policy/NAT/object diff содержит отдельный код, но не считается завершённым интегрированным сценарием.

Последняя записанная Windows-сборка 0.3.2 завершилась успешно без запуска приложения; это не подтверждение runtime. Результат старой packaged-самопроверки 0.3.0 нельзя переносить на 0.3.2.

Для прежнего коммита `c170560` [GitHub Actions](https://github.com/CheKecha19/Arxion/actions/runs/41107886303): карты/архитектура и Python packaging успешны; quality, tests, smoke и security неуспешны. Причины здесь не переаттестованы. CI-сводка относится к этому запуску, а не ко всем будущим версиям.

До v1.0 новые тесты создаются только по запросу; автоматические проверки выполняются в CI. Локальный запуск требует прямого запроса — [AGENTS.md](AGENTS.md).

## Roadmap

1. Развивать запрошенные функции приложения; исправлять конкретные проблемы, сохраняя совместимость и доказательства.
2. По согласованным приоритетам закрывать ограниченные платформенные/policy/cloud-сценарии из единого backlog выше.
3. Перед v1.0 отдельно определить стратегию тестирования, ревизии кода, чистых ОС и релизных подтверждений. До этого не расширять тестовый контур автоматически.
4. Enterprise/server-функции — после стабилизации локального продукта и отдельного выбора архитектуры.

Исследовательский roadmap из архива не является обязательством реализовать все предложения и не подтверждает точность 99,9%. Уязвимости/attack-vector management и автоматическое применение изменений политик не входят автоматически в эту программу.
