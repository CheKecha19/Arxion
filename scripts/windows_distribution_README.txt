Firewall Compliance — локальное приложение для Windows x64

Запуск: дважды щёлкните FirewallCompliance.exe.
Python отдельно устанавливать не требуется.
При переносе копируйте всю папку, включая каталог _internal.

Начало работы:
1. Нажмите «Новый проект» и задайте название площадки.
2. Нажмите «Добавить данные» и выберите файлы / папку либо облачное подключение.
3. Проверьте форматы и связи устройств. Неоднозначные связи подтверждаются
   двойным щелчком по строке. Ненужные файлы можно убрать из списка.
4. Нажмите «Запустить проверку файлов» в «Операции → Файлы и проверки». Все семь проверок включены по умолчанию.
5. В сводке проверьте обработанные, частичные и неподдержанные конфигурации.
6. В «Анализ → Проблемы» разберите результаты и при необходимости сохраните
   статусы и комментарии. Для общего отчёта откройте «Отчёты».

История проектов: %LOCALAPPDATA%\FirewallCompliance\projects.sqlite3.
Полные исходные конфигурации не копируются. Сохраняются нормализованные
результаты и ограниченные выдержки доказательств. После перезапуска для
повторных проверок нужен исходник с совпадающим SHA-256.
Сохранённые данные и отчёты могут содержать реальные адреса из конфигураций.

Поддержка: ограниченные ACL Cisco ASA, HP/Aruba AOS-Switch/AOS-CX и Comware.
Juniper и ArubaOS controller session ACL в эту версию не входят.
Сетевые инструменты ASA находятся в «Анализ → Расширенные инструменты»; дополнительные
документы остаются в памяти до закрытия и экспортируются отдельно.
Ноль находок не означает доказанную безопасность. Ограничения и ошибки
приведены в сводке и отчётах. Итоговая достижимость и NAT/PBR не вычисляются.

Предусмотрены Windows 10/11 x64. Эта сборка проверена на текущем Windows 10;
испытание на отдельной чистой Windows 11 ещё не проводилось.

Навигация: Обзор, Инфраструктура, Анализ, Операции, Отчёты; настройки отдельно.
Карточка ресурса: сведения, правила, объекты, проблемы, история и источники.
Кнопка «Назад» восстанавливает запуск, фильтры и выбор.
Cloud.ru: VMware, Advanced и Evolution. Сбор не выполняет локальные проверки ACL.
