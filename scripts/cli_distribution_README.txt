Arxion CLI для Windows x64

Распакуйте ZIP целиком. ArxionCLI.exe и каталог _internal должны оставаться рядом.
Python, uv, Docker и графическая оболочка для запуска не требуются.

PowerShell:
  .\ArxionCLI.exe version
  .\ArxionCLI.exe --help
  .\ArxionCLI.exe analyze C:\Exports\synthetic.cfg > result.json
  .\ArxionCLI.exe analyze C:\Exports\synthetic.cfg --extended-policy-checks > extended.json

CLI работает с локальными экспортами. Результат analyze — JSON Firewall Assurance.
Условия с недостаточными данными сохраняют partial/unknown. Само отсутствие
находок не подтверждает безопасность. Полноту экспорта указывайте только при
наличии основания; параметры и дополнительные проверки описаны в --help.

manifest.json содержит SHA-256 каждого файла поставки, включая SBOM.cdx.json.
Сам manifest исключён из собственного списка; SHA-256 ZIP публикуется отдельным
файлом .zip.sha256. Эти хеши обнаруживают изменение файлов, но не удостоверяют
издателя. Цифровая подпись и чистая среда Windows 10/11 отдельно не проверены.

SBOM.cdx.json описывает реально собранные Python-компоненты по Analysis TOC,
версию CPython и отдельные native-файлы с SHA-256. Версии и лицензии неизвестных
DLL не выдумываются. Нераспознанные Python-модули перечислены в manifest.json.
PyInstaller в SBOM обозначает необходимые runtime hooks сборщика, а не наличие
его сборочной команды или всего dev-окружения в поставке. Отпечатки фактических
входных модулей и uv.lock фиксируются отдельно от идентификатора Git-коммита.

Не переносите в поставку ключи интеграций, настройки проектов и клиентские
конфигурации. Сборка не включает данные пользовательских проектов.
