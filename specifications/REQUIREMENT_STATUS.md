## Правила обновления

TASK-015 меняет доступность сценариев: общая инфраструктура и история операций,
карточки с переходами к доказательствам, фильтры и навигация назад, явный выбор
запуска для отчёта. Доменные FR этой перестройкой не расширены. Cloud.ru VMware,
Advanced и Evolution представлены данными API; локальные checks над ними не
выполняются. Карта ACL по FR-023 остаётся следующим отдельным этапом.

- Изменение строки требует проверки реализации и ссылки на TASK/ADR либо раздел аудита.
- «Частично» не меняется на «реализовано» только по числу тестов или наличию модели.
- Текущее CLI создаёт ревизию в памяти. Qt desktop хранит policy-проекты в SQLite; общего доменного AnalysisResult пока нет.
- Desktop UI расширяет доступность уже реализованных сценариев, но не меняет границу
  сетевого evaluator, поддержку производителей или критерии полноты. Структурный diff
  не становится семантическим благодаря наличию экрана; SR-005 остаётся открытым.
- После изменения контракта одновременно обновляются DOMAIN_MODEL, SCHEMA_MIGRATIONS и CURRENT_STATE.
