# Словарь терминов

| Термин | Значение |
|---|---|
| Конфигурация | Экспортированное представление настроек одного устройства или его контекста. |
| Снимок | Неизменяемый результат импорта конфигурации в конкретный момент. |
| Ревизия устройства | Неизменяемый aggregate снимка: конфигурация и доступные сетевые факты одного устройства в момент импорта. |
| Источник ревизии | Метаданные документа, входящего в ревизию: отдельный идентификатор, имя, SHA-256, назначение и время получения без raw content. |
| Импортированные данные | Факты, извлечённые из конфигурации или экспортированного состояния устройства. |
| Ручные данные | Дополнения пользователя к топологии; они не выдаются за результат парсинга. |
| Парсер | Адаптер, который читает формат производителя и возвращает `ParseResult`. |
| Нормализация | Преобразование вендорской конфигурации в общую доменную модель. |
| Правило | Упорядоченное решение политики доступа. |
| Finding | Единый результат security-, policy- или compliance-проверки. |
| Evidence | Данные и логический путь, подтверждающие finding. |
| Check | Независимая проверка, создающая findings. |
| Control | Техническое требование стандарта или внутренней политики. |
| Покрытие парсера | Измерение того, какая доля значимых конструкций входной конфигурации понята парсером. |
| Source mapping | Связь нормализованной сущности с исходным файлом, строкой или путём объекта. |
| Unsupported | Конструкция распознана как существующая, но не поддерживается текущим парсером. |
| Unknown | Необходимые данные есть либо ожидаются, но надёжно определить их нельзя. |
| False positive | Finding, подтверждённо не являющийся реальной проблемой. |
| Accepted risk | Реальная проблема, риск которой формально принят уполномоченным лицом. |
| Запрос достижимости | Проверка потенциального трафика для заданных источника, назначения и сервиса. |
| Шаг пути | Объяснимое решение одного узла на маршруте: route, policy, NAT или ограничение данных. |
| CheckResult | Findings одной проверки вместе с версией, полнотой и причинами ограничений; пустой partial результат не означает отсутствие проблем. |
| Полнота анализа | Какие входы и конструкции проверены в заявленной области; не равна уверенности отдельного finding. |
| Confidence | Уверенность в конкретном утверждении finding, а не гарантия безопасности всей конфигурации. |
| Время наблюдения | Время состояния устройства с указанным происхождением; не выводится автоматически из filesystem mtime. |
| Provenance | Связь факта с документом, позицией, способом и временем получения; не заменяет доказательство полноты набора. |
| RIB | Таблица маршрутизации устройства; набор настроенных статических маршрутов сам по себе не доказывает её полноту. |
