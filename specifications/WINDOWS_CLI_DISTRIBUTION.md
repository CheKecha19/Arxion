# Windows CLI без Docker

Статус: реализован воспроизводимый рецепт консольной поставки и выполнена
нативная проверка на текущей Windows 10 x64. Это не проверка чистых Windows 10/11
и не публикация релиза v0.4. Приложение в данном контрольном срезе имеет версию 0.3.0.

## Сборка

Из корня подготовленного рабочего каталога:

```powershell
.\scripts\build_cli.ps1
```

Окружение `.venv` предварительно создаётся существующим locked setup проекта.
Сам builder не устанавливает зависимости, не загружает runtime и не использует
Docker. Требуются Windows x64, Git, Python/PyInstaller из подготовленной `.venv`.

Результаты:

- `dist/ArxionCLI/ArxionCLI.exe` и `_internal/` — переносимая консольная папка;
- `dist/ArxionCLI/README.txt` — использование и существенные ограничения;
- `dist/ArxionCLI/manifest.json` — состав, версии и SHA-256;
- `dist/ArxionCLI/SBOM.cdx.json` — CycloneDX 1.6;
- `dist/ArxionCLI-windows-x64.zip` и `.zip.sha256` — архив и контрольная сумма;
- `build/ArxionCLI/` — отдельные spec, Analysis, временная сборка и smoke-доказательства.

GUI-папка `dist/FirewallCompliance` и её промежуточные данные не используются.
До операций PyInstaller с `--noconfirm` проверяются абсолютные цели внутри
рабочего каталога и отсутствие reparse points по всему пути. Запущенный CLI
не завершается автоматически: builder отказывается заменять его файлы.

## Воспроизводимость

Builder устанавливает `PYTHONHASHSEED=0`, отключает UPX и фиксирует
`SOURCE_DATE_EPOCH`. По умолчанию используется время текущего Git-коммита;
явный параметр или одноимённая переменная окружения переопределяют его:

```powershell
.\scripts\build_cli.ps1 -SourceDateEpoch 1793103049
```

Одинаковые исходники, interpreter, зависимости, toolchain и epoch являются
входным контрактом. Само совпадение Git-коммита недостаточно для грязного
рабочего каталога: manifest дополнительно фиксирует хеш фактически собранных
Analysis-входов и `uv.lock`. Отпечаток не подменяется версией приложения.

ZIP использует сортированный список файлов, фиксированные UTC-времена
с разрешением ZIP в две секунды, одинаковые Unix modes и уровень deflate.
Время раньше 1980 года ограничивается только для ZIP; исходный epoch остаётся
в manifest/SBOM. Пути с traversal, абсолютные пути, Windows device names,
alternate streams, неоднозначные имена, symlinks/junctions и коллизии регистра
отвергаются. Архив строится во временном файле, затем проверяется по именам,
размерам и SHA-256 содержимого и атомарно заменяет целевой ZIP.

Побайтовая воспроизводимость на других версиях Windows, Python, PyInstaller,
zlib или в другом размещении исходников не заявляется. Смена версии зависимостей
либо упаковщика требует нового доказательства, а не сравнения только версии ПО.

## Состав и SBOM

Python-компоненты определяются по фактически собранным путям Analysis TOC
и установленным distribution RECORDs. Произвольные dev-зависимости из `.venv`
в перечень не добавляются. CPython указан отдельно с фактической версией;
собранные EXE/DLL/PYD/base ZIP отражаются отдельными file-компонентами с SHA-256.
Версии и лицензии неизвестных native-файлов не угадываются.

Неатрибутированные Python-модули явно перечисляются в manifest; неоднозначное
владение одним модулем разными distributions отвергается. PyInstaller может
присутствовать как владелец обязательных runtime hooks: это не означает включение
сборочной программы и всех её dev-зависимостей. Qt, Tk, pytest, Hypothesis и
другие явно исключённые GUI/dev-модули запрещены дополнительной проверкой состава.

Manifest включает SBOM и все файлы поставки, кроме самого себя. Проверка
`scripts/package_inventory.py verify <папка>` отвергает отсутствующие, изменённые
и незаявленные файлы. Эти хеши обеспечивают проверку целостности, но не удостоверяют
издателя и не заменяют цифровую подпись либо dependency vulnerability audit.

## Нативная самопроверка

После сборки запускается именно `ArxionCLI.exe`, без Python/uv в PATH и с удалёнными
`PYTHONPATH`, `PYTHONHOME`, `VIRTUAL_ENV`. В PATH остаются только системные папки.
Проверяются `version`, обычный анализ синтетического ASA input и расширенный
каталог. Результаты должны быть корректным JSON с версией проекта и ожидаемыми
checks. Файлы входа и вывода создаются только в `build/ArxionCLI/smoke/`.

Нативный контрольный срез: CPython 3.12.13, PyInstaller 6.22.3, Windows 10
10.0.19045 x64, epoch 1793103049. Обычный каталог — семь checks; расширенный — 11.
В фактической поставке нет GUI DLL; 1117 Analysis entries атрибутированы без
неизвестных Python-модулей. Результаты и hashes: `build/ArxionCLI/smoke-final/`,
`build/ArxionCLI/reproducibility.json`, `dist/ArxionCLI/manifest.json`.

32 focused regression tests проверяют детерминированность ZIP/manifest/SBOM,
фактическое владение distribution, native junction escape, traversal, tampering,
неизвестные компоненты и изменение исходников при прежнем Git-коммите.
Чистые офлайн Windows 10/11 без Python/Docker и отдельная проверка прав обычного
пользователя остаются открытым выпускным требованием.
