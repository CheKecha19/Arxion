# Навигация по спецификациям

Этот файл является входной точкой при начале новой рабочей сессии. Сначала читаются документы из раздела «Постоянные правила», затем документы, относящиеся к текущей задаче.

Исполнение полного roadmap v2: [небольшие шаги XS, один active и проверяемая очередь](roadmap-v2/IMPLEMENTATION_STEPS.md).

## Использование приложения

| Документ | Назначение |
|---|---|
| [USER_GUIDE.md](USER_GUIDE.md) | Установка, запуск, анализ файлов, findings/evidence, отчёты, ревизии и устранение ошибок |
| [NETWORK_UI_GUIDE.md](NETWORK_UI_GUIDE.md) | Сетевые вкладки, явные metadata, примеры импорта/query/binding и forwarding |

Пользовательские руководства описывают рабочее пространство от 14.10.2026.
Целевые требования ниже могут включать ещё не реализованные возможности.

## Правило актуальности

Если поведение, граница продукта или публичный контракт изменились, задача считается незавершённой до обновления связанной спецификации. При конфликте документов приоритет имеют обязательные архитектурные и кибербезопасностные требования заказчика, затем принятые ADR, затем остальные спецификации.
