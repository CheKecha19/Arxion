## Границы согласованного первого этапа

PySide6, текущая тема, доменные контракты и существующие backend-операции сохраняются.
Облачный сбор не называется анализом ACL. Ресурсы не объединяются по имени/IP.
Изменение UI не переносит автоматически marks между запусками. Неизвестные/частичные
данные не превращаются в успешные проверки. Исходники подключаются только по SHA-256.

Следующий этап исходного плана — карта ACL на готовом backend. Сохранённые фильтры,
семантический diff, новые checks, нормализация облачных политик и полный сетевой
анализ перечислены в плане как дальнейшие самостоятельные задачи, не функции
первого этапа UI. Их нельзя объявлять реализованными по результатам перестройки.
