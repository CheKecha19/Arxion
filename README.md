Локальное Windows-приложение для анализа конфигураций сетевого оборудования, межсетевых экранов и облачных правил. Версия **0.3.2**, разработка до v1.0.

## Запуск

Portable: открыть `dist/FirewallComplience_v0.3.2/FirewallComplience_v0.3.2.exe`. Для переноса нужна вся папка вместе с `_internal`; внешний Python не требуется.

Из исходников после явно запрошенной подготовки окружения:

```powershell
uv sync --locked --all-groups
uv run firewall-compliance-desktop
```

Для анализа: создать проект → добавить файлы/папку → «Операции → Файлы и проверки» → выбрать проверки → запустить → изучить проблемы, evidence и полноту → экспортировать отчёт.

CLI:

```powershell
uv run firewall-compliance analyze "C:\configs\device.cfg"
```

UserGate/Ideco собирают собственные JSON-снимки; Cloud.ru VMware поддерживает анализ Edge Firewall. Поддержка ограничена: отсутствие находок и связи на карте не доказывают безопасность или сквозную достижимость. Подробности — DOCUMENTATION.md.

## Архив

Исторические исследования, планы, TASK, журналы и README тестовых данных перемещены в корневой `архив` без подпапок. Имена содержат прежний путь с разделителем `__`; соответствие записано в `архив/ARCHIVE_INDEX.md`.

Архив добавлен в `.gitignore`: это локальная сохранённая история, она не попадёт в новые коммиты. Документы архива не являются действующими инструкциями. Утилиты `.agents/skills` и README ресурсов остаются рядом со своими компонентами.

Требования, архитектурные решения и технические контракты возвращены в рабочую папку [спецификации](спецификации/README.md); они не относятся к списанным историческим материалам.
